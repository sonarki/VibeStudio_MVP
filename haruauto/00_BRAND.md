# 하루자동화 (ONEDAY AUTOMATION)

> 반복 업무 1개를, 24시간 안에 자동화합니다. 못 지키면 전액 환불합니다.

---

## 1. 한 줄 정의

중소기업·소상공인이 **매일 사람 손으로 반복하는 업무 딱 1개**를 골라,
**24시간 안에 돌아가는 자동화 시스템으로 만들어 납품**하는 초단기 실행 서비스.

## 2. HookForge와의 분리 선언

| 항목 | HookForge | 하루자동화 |
|---|---|---|
| 판매물 | 영상/광고 크리에이티브 | 업무 자동화 시스템 (코드) |
| 고객 | 마케터·크리에이터 | 사장·운영자·관리자 |
| 고객의 목적 | 매출 올리기 | 인건비/시간 줄이기 |
| 납품물 | 영상 파일 | 동작하는 스크립트·연동 |
| 브랜드 | 완전 별개 | 완전 별개 |
| 공유 자산 | — | **Gumroad 결제만 공유** |

이메일·SNS·도메인·문구·톤 전부 신규. 상호 링크 금지, 상호 언급 금지.

## 3. 타깃 (우선순위 순)

1. **이커머스 셀러** — 주문/송장/재고/리뷰 정리를 엑셀로 손수 하는 곳
2. **소규모 에이전시·스튜디오** — 리포트·정산·클라이언트 보고 수작업
3. **학원·병원·공방** — 예약/문자/출결/정산 반복 입력
4. **B2B 영업팀** — 리드 정리, CRM 수기 입력, 주간 집계

공통 조건: **사람이 매일/매주 같은 일을 반복하고, 그게 몇 시간씩 든다.**

## 4. 상품 구조

### LITE — ₩1,900,000
- 파일/시트 기반 자동화 1건
- 예: 엑셀 취합·정제 자동화, 반복 문서 자동 생성, 데이터 정리 스크립트
- 납기: **24시간**

### SPRINT — ₩4,900,000  ← 주력
- 시스템 연동 자동화 1건
- 예: 쇼핑몰↔시트↔알림 연동, API 연동 집계·발송, 스케줄 자동 실행
- 납기: **24시간**
- 포함: 30일 무상 수정 + 사용 가이드 문서 + 인수인계 영상

### 목표 조합 (24시간 ₩1,000만)
- SPRINT 2건 = ₩980만 ← 메인 시나리오
- SPRINT 1건 + LITE 3건 = ₩1,060만
- SPRINT 2건 + LITE 1건 = ₩1,170만

**필요한 건 200명이 아니라 2명입니다.**

## 5. 가격 정당화 (상담 시 그대로 사용)

> 직원 1명이 이 업무에 하루 3시간을 씁니다.
> 월 22일 × 3시간 = 66시간.
> 시급 2만원 기준 월 132만원. 연 1,584만원.
>
> SPRINT 가격은 ₩490만입니다. **회수 기간 3.7개월.**
> 그 이후로는 매년 1,500만원이 그냥 남습니다.

## 6. 환불 보장 (문구 확정 — 변경 금지)

> 결제 후 24시간 안에 동작하는 자동화를 인도하지 못하면,
> 이유를 묻지 않고 **전액 환불**합니다. 차감도, 위약금도 없습니다.

**이 약속은 진짜로 지킨다. 못 지킬 것 같으면 애초에 수주하지 않는다.**
수주 전 무료 진단(30분)에서 24시간 내 구현 가능 여부를 먼저 판정한다.

## 7. 정직 원칙 (하드 룰)

우리는 이번 주에 시작한 신생 팀입니다. 실적이 없습니다. 따라서:

- ❌ 가짜 후기·가짜 고객사 로고·가짜 누적 실적 숫자 — **절대 사용 금지**
- ❌ "1,000개 기업이 선택한" 류의 미검증 문구 — 금지
- ❌ 존재하지 않는 팀 규모·경력 — 금지
- ✅ 신규 런칭임을 먼저 밝히고, **위험을 우리가 전부 진다**로 이긴다
- ✅ 검증 가능한 것만 말한다 (납기, 환불 조건, 작업 범위)

신뢰를 위조하면 첫 건은 팔릴지 몰라도 브랜드가 하루 만에 죽습니다.
우리가 파는 건 신뢰이므로, 신뢰만은 진짜여야 합니다.
