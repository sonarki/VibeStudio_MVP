# 마켓플레이스 제안서 — 위시켓 · 크몽 · 숨고 · 아웃소싱 게시판

> **이게 승부처입니다.** 콜드메일로 수요를 만드는 게 아니라, 이미 "돈 낼 테니 해달라"고
> 글을 써 놓은 사람에게 갑니다. 우리에게 없는 배포(distribution)를 마켓플레이스가 대신합니다.

## A. 타깃 공고 찾는 법

### 위시켓 (wishket.com) — 1순위
검색 키워드를 **하나씩** 넣고 최근 7일 공고만 봅니다.
```
자동화 / 업무자동화 / 엑셀 자동화 / 크롤링 / 데이터 수집
API 연동 / 구글시트 연동 / 스크립트 / RPA / 매크로
```
**우선 지원 조건**
- 예산 300만 ~ 1,500만원
- 마감까지 3일 이상 남음
- 지원자 수 10명 이하 (적을수록 좋음)
- 요구사항이 1~2문단으로 짧다 → 범위가 작다 → 24시간 가능

**거르는 공고**
- "장기 상주", "주 3일 출근" → 우리 모델 아님
- 예산 미기재 + 요구사항 3페이지 → 범위 폭발
- 이미 지원자 30명 이상

### 크몽 (kmong.com) — 2순위
- **[의뢰하기] 게시판**에서 같은 키워드 검색 → 직접 제안
- 동시에 **전문가 서비스 등록**도 해둡니다 (아래 D 참고)

### 숨고 (soomgo.com) — 3순위
- 카테고리: IT·프로그래밍 → 프로그램 개발 / 데이터
- 고수 등록 후 요청서가 오면 자동 매칭

### 기타 (여력 되면)
- 이커머스 셀러 카페 (셀러오션 등) 홍보 허용 게시판
- 오늘의집·네이버 스마트스토어 셀러 오픈채팅방
- 링크드인 검색: `"업무 자동화" 담당자` / 스레드 해시태그 `#업무자동화`

## B. 제안서 템플릿 (위시켓용 — 그대로 복붙 후 대괄호만 교체)

```
안녕하세요. 하루자동화입니다.

[공고에 적힌 업무를 한 문장으로 되풀이]
— 이 작업이 맞다면, 저희는 이걸 24시간 안에 납품합니다.

■ 제안 내용

1) 무료 진단 30분
   현재 그 업무를 어떻게 하고 계신지 화면 공유로 보겠습니다.
   24시간 안에 구현 가능한지 이 자리에서 판정해 드립니다.
   불가능하면 불가능하다고 말씀드리고 지원을 철회합니다.

2) 범위 확정서
   무엇을 만들고 무엇은 만들지 않는지 문서로 못 박습니다.
   추가 요청으로 일정이 늘어나는 일이 없습니다.

3) 제작 24시간
   착수 후 24시간 안에 동작하는 상태로 인도합니다.

4) 인수인계 30분
   실제 데이터로 눈앞에서 돌려 확인시켜 드립니다.
   사용 가이드 문서와 조작 영상을 함께 드립니다.
   개발자가 없어도 담당 직원분이 혼자 쓸 수 있는 상태까지가 납품입니다.

■ 견적

[LITE ₩1,900,000 / SPRINT ₩4,900,000 중 택1]
숨은 비용, 월 구독료 없습니다. 결과물(코드·설정)은 전부 귀사 소유입니다.
납품 후 30일 무상 수정 포함.

■ 보장

착수 후 24시간 안에 인도하지 못하면 이유를 묻지 않고 전액 환불합니다.
차감도 위약금도 없습니다.

■ 먼저 밝힙니다

하루자동화는 최근 시작한 신생 팀입니다. 플랫폼 내 수행 이력이 없습니다.
그래서 위험을 저희가 전부 지는 조건으로 제안드립니다.
진단은 무료고, 안 될 것 같으면 지원을 철회하고, 못 지키면 전액 환불합니다.
이력이 없다는 이유로 걸러지는 게 당연하다고 생각하기 때문에,
걸러지지 않을 만한 조건을 대신 걸었습니다.

■ 확인 부탁드릴 것 (진단 전 미리 주시면 더 빠릅니다)

- 현재 그 업무에 하루/주 몇 시간이 드는지
- 다루는 파일 형식 또는 사용 중인 서비스 이름
- 담당자분이 개발 지식이 있으신지

30분만 내주시면 되는 일인지 아닌지부터 알려드리겠습니다.

하루자동화 (ONEDAY AUTOMATION)
CONTACT_EMAIL
```

## E. 하드 룰 (어기면 브랜드가 죽습니다)

1. **없는 이력을 만들지 않는다.** "포트폴리오 100건" 같은 문구 절대 금지.
   신생 팀임을 먼저 밝히는 게 이 제안서의 무기입니다.
2. **24시간에 안 될 것 같으면 지원을 철회한다.** 환불 보장은 진짜로 지켜야 합니다.
3. **한 번에 3건 이상 수주하지 않는다.** 동시 납품 실패 = 환불 폭탄 + 평판 손상.
4. **플랫폼 규정을 지킨다.** 외부 결제 유도가 금지된 플랫폼에서는 Gumroad 링크를 보내지
   않고 플랫폼 결제를 따릅니다. 규정 위반 시 계정 정지 = 배포 채널 상실.
5. **같은 제안서를 무차별 복붙하지 않는다.** 첫 두 줄은 반드시 공고 내용으로 개인화.
