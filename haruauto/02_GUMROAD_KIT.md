# Gumroad 상품 등록 복붙킷

> 캡틴 작업 시간: **약 8분**. 아래를 위에서 아래로 그대로 복사해서 붙여넣으시면 됩니다.

---

## 사전 설정 (1회만)

1. Gumroad → Settings → Payments → **통화(Currency)를 KRW 또는 USD로 확인**
   - KRW 미지원 시 USD로 등록하고 환산가 사용 (아래 병기)
2. Settings → Advanced → **"Require customers to provide a name" 켜기** (B2B 응대용)

## 상품 1 — SPRINT (주력)

### Product name
```
하루자동화 SPRINT — 반복 업무 1건 24시간 자동화 (시스템 연동)
```

### Price
```
KRW 4,900,000
```
> USD만 가능한 경우: **$3,600** (1,360원/$ 기준 · 결제일 환율에 따라 변동 안내)

### URL slug
```
haruauto-sprint
```

### Summary (한 줄 설명)
```
회사에서 매일 반복하는 업무 1건을 24시간 안에 자동화 시스템으로 만들어 드립니다. 못 지키면 전액 환불합니다.
```

### Description (본문 — 전체 복사)
```
■ 무엇을 드리나요

회사에서 매일·매주 사람 손으로 반복하는 업무 딱 1건을 골라 주시면,
결제 후 24시간 안에 실제로 돌아가는 자동화 시스템으로 만들어 납품합니다.

SPRINT는 '시스템 연동' 등급입니다.
- 쇼핑몰 · CRM · 구글시트 · 메신저 간 데이터 자동 연동
- API 연동 집계 및 자동 발송 (메일 · 문자 · 알림)
- 정해진 시각에 자동 실행 (스케줄링)


■ 포함 사항

- 자동화 시스템 제작 및 납품 (코드 · 설정 전부 고객사 소유)
- 사용 가이드 문서
- 인수인계 세션 30분 + 조작 영상
- 납품 후 30일 무상 수정


■ 진행 순서

1. 무료 진단 30분 — 24시간 안에 가능한 작업인지 먼저 판정합니다.
   불가능하면 결제받지 않습니다.
2. 범위 확정서 — 무엇을 만들고 무엇은 안 만드는지 문서로 확정합니다.
3. 결제 → 24시간 제작
4. 인수인계 30분

※ 이 상품은 무료 진단과 범위 확정을 마친 고객님만 결제해 주세요.
   진단 없이 결제하신 경우 진단 후 진행이 어렵다고 판단되면 즉시 전액 환불해 드립니다.


■ 전액 환불 보장

결제 후 24시간 안에 동작하는 자동화를 인도하지 못하면
이유를 묻지 않고 전액 환불합니다. 차감도 위약금도 없습니다.

기준 시각은 범위 확정서 서명 및 결제 완료 시점입니다.
고객사 계정·데이터 접근 권한 제공이 지연되면 그 시간만큼 기준 시각이 밀립니다.
범위 확정서에 없는 추가 요청은 납기 대상에 포함되지 않습니다.


■ 진행하지 않는 작업

- 공인인증 · 보안 로그인이 필수인 내부망 시스템
- 대상 서비스의 이용약관이 자동화를 금지한 경우
- 법적으로 사람의 확인이 필요한 절차


■ 먼저 밝힙니다

하루자동화는 이번 주에 시작한 신생 팀입니다.
그래서 후기도 고객사 로고도 실적 숫자도 없습니다.
대신 위험은 저희가 전부 집니다.
진단은 무료고, 안 될 것 같으면 결제받지 않고, 못 지키면 전액 돌려드립니다.


■ 문의

CONTACT_EMAIL
문의 시 알려주시면 빠릅니다 — 회사명 / 자동화하고 싶은 업무 1줄 / 현재 소요 시간
```

### Receipt / Content (구매 후 자동 발송 내용)
```
결제 감사합니다. 지금부터 24시간 타이머가 시작됩니다.

【지금 바로 회신해 주실 것】
1. 담당자 성함 · 연락처 (카톡 또는 전화)
2. 범위 확정서에 적힌 작업 대상 계정/파일 접근 권한

접근 권한이 준비되는 즉시 제작에 들어갑니다.
권한 제공이 지연되면 그 시간만큼 납기 기준 시각이 뒤로 밀립니다.

작업 중에는 회의로 시간 뺏지 않습니다. 완성되면 바로 연락드립니다.

문의: CONTACT_EMAIL
하루자동화 (ONEDAY AUTOMATION)
```

## 등록 후 캡틴이 저에게 알려주실 것

```
SPRINT 링크: https://______.gumroad.com/l/haruauto-sprint
LITE   링크: https://______.gumroad.com/l/haruauto-lite
신규 이메일: ______@gmail.com
```

이 3줄만 주시면 랜딩페이지·제안서·스크립트의 `CONTACT_EMAIL`과
결제 링크를 제가 전부 일괄 교체하고 배포합니다.
